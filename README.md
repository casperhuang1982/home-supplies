# 家庭消耗品管理

記錄家裡消耗品（洗髮乳、沐浴乳、牙膏、尿布、奶粉…）**每次買多大、多少錢、在哪買、用多久**，
自動推算**下次該補貨的日期**。

單一檔案、零相依套件，用瀏覽器打開 `index.html` 就能用。

---

## 功能

| 頁籤 | 內容 |
|---|---|
| 儀表板 | 需補貨數、本月／今年支出、依急迫度排序的補貨提醒 |
| 品項與庫存 | 卡片顯示庫存、還能撐幾天、狀態進度條，點進去看完整歷史 |
| 購買記錄 | 表格＋篩選，一鍵標記「開封」／「用完」 |
| 統計分析 | 每月支出長條圖、分類與通路佔比、同品項跨通路的單價比較 |

### 補貨日怎麼算

1. 從歷史的「開封日 → 用完日」算出**平均一件可用幾天**（除以件數，買整箱也準）
2. 使用中的批次：開封日 ＋ 平均天數 × 件數 ＝ 預估用完日
3. 未開封的庫存再往後疊加
4. 減掉設定裡的提前天數（預設 7 天）＝ **建議補貨日**

### 條碼掃描

按頂端「📷 掃描」，三種方式擇一，前者失敗會自動退到後者：

1. **相機即時掃** — 優先用瀏覽器內建 `BarcodeDetector`，沒有就載入 ZXing
2. **拍照辨識** — 相機權限被擋時使用
3. **手動輸入** — 保底

掃到已綁定的條碼，會直接開啟記帳表單並**帶入上次的規格、件數、價格、店家**；
沒看過的條碼則先問要綁到哪個品項。

## 資料存在哪

| 使用方式 | 儲存位置 | 跨裝置 |
|---|---|---|
| 開本機 `index.html` | 瀏覽器 localStorage | ❌ 各裝置獨立 |
| 開 Claude Artifact 版 | 該 Artifact 的雲端資料庫 | ✅ 手機／電腦即時同步 |

同一份程式碼會自動偵測：偵測不到雲端就退回 localStorage。
右上角徽章顯示目前狀態（`☁️ 雲端同步` / `💾 本機`）。

> **資料不會進 git。** 這個 repo 只有程式碼，購買記錄存在瀏覽器或 Claude 雲端。

搬家用「匯出備份」產生 JSON，到另一邊按「匯入」即可。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | **本體**，唯一的原始碼。直接用瀏覽器開啟 |
| `build-artifact.py` | 建置腳本，產生雲端版 |
| `artifact.html` | 建置產物，不進版控（見 `.gitignore`） |

### 重新發佈雲端版

改完 `index.html` 後：

```bash
python build-artifact.py
```

產生的 `artifact.html` 拆掉了 `<!doctype>` / `<html>` / `<head>` / `<body>` 外殼，
因為 Claude Artifact 平台發佈時會自己補上。
**這個檔案不能當成一般網頁使用**——丟到 GitHub Pages 上會是壞頁面。
